# Threat Modeling Fundamentals

This folder contains threat modeling exercises completed as part of the cybersecurity certification program.

Each task analyzes a different system using STRIDE, trust boundary mapping, and DREAD risk scoring.

## Tasks

- `0-ecommerce_platform.md` - Threat model for an e-commerce platform (React frontend, Node.js backend, PostgreSQL, Stripe payments).
- `1-healthcare_mobile_app.md` - Threat model for a healthcare mobile app (mobile client, REST API, cloud database, hospital system integration).
- `2-iot_smart_thermostat.md` - Threat model for an IoT smart thermostat (device firmware, Wi-Fi, mobile app, OTA updates).
- `3-financial_trading_platform.md` - Threat model for a financial trading platform (real-time trading, fund transfers, automated trading rules, SEC/FINRA compliance).
